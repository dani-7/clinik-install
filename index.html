Install Clinik

Version 0.1.0 (build 1) · built 20 October 2026

  • Must be opened in Safari — Chrome and other browsers cannot install apps.
  • Works only on iPhones registered to the Clinik Apple Developer account.
  • After installing: Settings → General → VPN & Device Management, tap the Clinik entry and choose Trust.
  • Then: Settings → Privacy & Security → Developer Mode → On, and restart when asked.
